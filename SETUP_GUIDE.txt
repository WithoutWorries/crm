QUICK START
===========

1. Navigate to the project:
   cd /sessions/affectionate-kind-ritchie/solo-crm

2. Install dependencies:
   npm install

3. Set up database connection:
   Copy .env.example to .env.local
   Edit .env.local with your PostgreSQL connection string:
   DATABASE_URL="postgresql://user:password@localhost:5432/solo_crm"

4. Push schema and seed data:
   npm run db:push
   npm run db:seed

5. Start development server:
   npm run dev

6. Open browser:
   http://localhost:3000

7. Login with:
   Email: consultant@solocrm.com
   Password: (any password)

TROUBLESHOOTING
===============

If npm install fails:
  - Ensure Node.js 18+ is installed
  - Try clearing npm cache: npm cache clean --force
  - Delete node_modules and package-lock.json, then reinstall

If database connection fails:
  - Verify PostgreSQL is running
  - Check DATABASE_URL format in .env.local
  - Ensure database user has correct permissions
  - Test connection with: psql [DATABASE_URL]

If pages don't load:
  - Check if npm run dev is running
  - Look at console for errors
  - Verify API routes return correct data
  - Check Prisma client is properly initialized

If styling looks wrong:
  - Run npm run build to rebuild Tailwind
  - Clear browser cache
  - Verify tailwind.config.ts is correct
